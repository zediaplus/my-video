# Zedia+ — موقع زيديا للخدمات الإعلامية

موقع تعريفي عربي (RTL) لشركة زيديا، مبني بـ HTML/CSS/JS بدون أي أدوات بناء.

## التشغيل محليًا
```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## الملفات
- `index.html` — محتوى الصفحة (من نحن، الخدمات، المميزات، العملاء، الأسئلة الشائعة، السياسات، التواصل)
- `styles.css` — التصميم وألوان الهوية (الأزرق والبرتقالي)
- `script.js` — القائمة، الحركات، شعارات العملاء، ونموذج التواصل الذي يرسل عبر واتساب
- `assets/` — الشعار، صورة المؤسس، وشعارات العملاء

## تعديلات سريعة
- رقم واتساب: `WHATSAPP_NUMBER` في `script.js`
- إضافة عميل: ضع الشعار في `assets/clients/` وأضفه لمصفوفة `CLIENTS` في `script.js`

## النشر
الموقع ثابت بالكامل، ويمكن نشره مجانًا على GitHub Pages أو Netlify أو Vercel.
