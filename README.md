# Zedia+ — موقع زيديا للتصميم والتسويق والطباعة

موقع عربي (RTL) تفاعلي بالكامل، مبني بـ HTML/CSS/JS بدون أدوات بناء.

## التشغيل محليًا
```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## تعديل المحتوى
كل نصوص وأرقام الموقع في ملف واحد: **`data/content.js`**
- `contact` — واتساب، البريد، لينكدإن، فيسبوك، بيهانس، رابط معرض الأعمال
- `stats` — الأرقام المتحركة (500 مشروع، 40 عميل، 25 مؤسسة…)
- `services` — الخدمات
- `mapsSteps` / `mapsProof` / `mapsVideo` — قسم خرائط جوجل (ضع رابط الفيديو في `mapsVideo` ليظهر داخل القسم)
- `driveFolderId` — معرض الأعمال المضمّن من Google Drive (يجب أن يكون المجلد مشاركًا لأي شخص لديه الرابط)
- `cv` — السيرة الذاتية: الخبرة، الشهادات، المهارات، التعليم، اللغات
- `clients` — شعارات العملاء (الملفات في `assets/clients/`)
- `testimonials`, `faq`, `policies`

## الملفات
- `index.html` — هيكل الصفحة
- `styles.css` — التصميم (وضع فاتح/داكن، حركات، تجاوب مع الجوال)
- `app.js` — بناء الأقسام من المحتوى، العدّادات، شريط الشعارات، الحركات، نموذج واتساب
- `assets/` — الشعار المتحرك، صور المؤسس، شعارات العملاء، عناصر الهوية

## النشر
الموقع ثابت بالكامل ويمكن نشره مجانًا على GitHub Pages أو Netlify أو Vercel.
